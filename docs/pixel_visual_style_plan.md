# План визуального окружения и интерактивной травы

## Текущий статус

На отдельной тестовой сцене реализован и проверен прототип окружения на основе
Dylearn 3D Pixel Art Grass Demo.

Основная сцена прототипа:
`res://scenes/prototypes/pixel_visual_style_prototype.tscn`.

Прототип пока не подключён к основным игровым локациям и не изменяет
`scenes/main.tscn`.

## Что уже реализовано

### Трава

- [x] Перенесены grass shader, текстуры травы и акцентных растений.
- [x] Трава создаётся одним `MultiMeshInstance3D`, а не отдельными узлами.
- [x] Реализован генератор:
  `res://scripts/effects/grass_multimesh_chunk.gd`.
- [x] Добавлено стабильное псевдослучайное размещение травинок.
- [x] Добавлены зоны исключения для дороги и тестовых объектов.
- [x] Плотность тестовой сцены установлена на `55 травинок/м²`.
- [x] На тестовой площадке отображается примерно `10 344` экземпляра травы.
- [x] Добавлена анимация ветра через world-space noise.
- [x] Анимация квантована до пяти визуальных обновлений в секунду.
- [x] Добавлено покачивание карточек в пространстве камеры.
- [x] Добавлена реакция травы на приближение персонажа.
- [x] Шейдер поддерживает до восьми ближайших интеракторов.
- [x] Настоящие отбрасываемые тени травы отключены ради производительности.
- [x] Трава получает toon-освещение и движущиеся облачные псевдотени.

### Поверхность земли и освещение

- [x] Перенесён Floor shader.
- [x] Цвет поверхности формируется несколькими world-space шумами.
- [x] Шумы и цветовые области земли согласованы с травой.
- [x] Перенесён общий Toon shader для непрозрачных объектов.
- [x] Перенесены глобальные параметры направления света и облаков.
- [x] Добавлены движущиеся облачные псевдотени.
- [x] Направленные тени объектов включены.
- [x] Исправлено исчезновение теней при перемещении камеры:
  - используется единая ортографическая область теней;
  - дальность теней увеличена с `30` до `60` метров;
  - преждевременное затухание отключено;
  - дальняя плоскость камеры увеличена до `80` метров.

### Тестовый персонаж и камера

- [x] Добавлен лёгкий `CharacterBody3D` для проверки окружения.
- [x] Управление работает через `WASD` и стрелки.
- [x] Передвижение ограничено размерами тестовой площадки.
- [x] Ортографическая камера плавно следует за персонажем.
- [x] Положение персонажа передаётся в grass shader.
- [x] Движение, камера и взаимодействие с травой проверены в Godot.

Скрипт тестового персонажа:
`res://scripts/prototypes/grass_demo_player.gd`.

### Решение по пиксельному рендеру

- [x] Был протестирован низкоразрешённый `SubViewport` с nearest-фильтрацией.
- [x] Были протестированы масштабы `1×` и `2×`.
- [x] Фильтр ухудшал уже пиксельный спрайт персонажа.
- [x] На текущем этапе принято решение не использовать общий пиксельный фильтр.
- [x] `SubViewport`, переключатели масштаба и тестовый UI удалены из сцены.
- [x] Сейчас сцена выводится напрямую основной 3D-камерой.

Пиксельный `SubViewport` можно повторно исследовать позже, но он не является
частью текущего выбранного варианта.

## Важные принятые решения

- Трава рисуется через `MultiMesh`, а не через тысячи отдельных узлов.
- Шум земли и травы рассчитывается в мировых координатах.
- Ветер и взаимодействие выполняются в vertex shader.
- Настоящие тени от каждой травинки пока не используются.
- Облачные тени являются дешёвым общим визуальным эффектом.
- Общий пиксельный фильтр сейчас отключён.
- 3D-тайлы и интерактивная трава могут использоваться вместе:
  тайлы формируют уровень, а трава накладывается отдельным декоративным слоем.
