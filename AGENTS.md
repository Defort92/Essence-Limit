## Project Overview

**Essence Limit** — тёмное фэнтези RPG на движке Godot 4. Основная цель игрока — пройти подземелье из 15 уникальных этажей. Игра разрабатывается на GDScript.

## Game Concept

**Жанр:** RPG, dark fantasy  
**Основная механика:** Открывается портал в подземелье с 15 фиксированными этажами. Каждый этаж имеет уникальную пассивную ауру, своих монстров и условного босса. При закрытии портала персонажа выбрасывает к входу. Время внутри подземелья течёт иначе — сколько бы игрок не провёл внутри, снаружи персонаж появится буквально как портал закроетя.

## Races (Расы)

| Раса | Уклон | Уникальность |
|------|-------|-------------|
| Люди | Универсал, только люди могут быть волшебниками и зачаровывать оружие | — |
| Варвары | Ближний бой (танк), не могут стать паладинами | Усиление через татуировки от шамана |
| Эльфы | Дальний бой | Связь с духами природы |
| Демоны | Ближний бой (ДПС), могут стать жрецами | Обряды усиления души — доп. слот эссенции |
| Ангелы | Дальний бой, магия, мощнее жреческие спеллы | Обряды усиления души — доп. слот эссенции |

Демоны и Ангелы конфликтуют между собой (давние разногласия после разделения).

## World Structure (Карта мира)

Центр — **Человеческий город** (портал в подземелье, основные прогресс-точки).  
По углам карты — стартовые локации рас, переходы к городу:
- Верх → Ангелы (белый камень, белая земля, жёлтая трава)
- Низ → Демоны (тёмная локация, частично разрушенные постройки)
- Право → Эльфы (двухуровневая лесная деревня: земля + дома на деревьях с канатными дорогами)
- Лево → Варвары (лесной лагерь, палатки, протоптанные тропинки)

## Core Mechanics

### Прокачка (нет очков характеристик за уровень)
- **Уровень** открывает только слот под эссенцию (кол-во слотов = уровень персонажа)
- **Опыт** даётся за: первое убийство каждого типа моба (повторные убийства — 0 XP), уникальные достижения, достижения внутри лабиринта, убийство уникального монстра/босса (1 раз за забег)
- Характеристики растут через: эссенции, уникальные достижения, расовые пассивки

### Эссенции
- Дают уникальные активные способности + фиксированные статы
- Получение: дроп с монстров, покупка у торговцев
- Удалить эссенцию можно только в городе за плату

### Снаряжение
- Слоты: тело, ноги, голова, оружие, вспомогательное (макс 3: кольца, повязки, пояса и т.д.)
- Оружие: одноручное (+ щит если свободна рука), двуручное, дальнобойное
- Получение: крафт у ремесленников, покупка, дроп, находки в подземелье

### Типы противников
- **Рядовые** — постоянный респавн
- **Уникальные** — фиксированное количество за открытие подземелья
- **Боссы этажа** — требуют выполнения условий для появления, бой по фазам, 1 призыв за забег
- **Скрытые уникальные** — триггерятся условиями, фиксированное число призывов, возможно бой по фазам

## Architecture Notes (по мере роста проекта)

Проект строится на **Godot 4** с **GDScript**. Рекомендуемая структура сцен:

```
res://
├── scenes/
│   ├── world/          # локации рас и город
│   ├── dungeon/        # этажи подземелья
│   ├── characters/     # игрок и NPC
│   ├── ui/             # HUD, меню, инвентарь
│   └── effects/        # ауры, анимации способностей
├── scripts/
│   ├── systems/        # core системы (XP, эссенции, снаряжение)
│   ├── entities/       # Player, Enemy, Boss
│   └── data/           # ресурсы-данные (Resource классы)
└── assets/
```

Ключевые системы для реализации в первую очередь:
1. `EssenceSystem` — слоты, установка/удаление, статы и абилки
2. `XPSystem` — отслеживание первых убийств каждого типа моба (Dictionary `mob_type → killed`)
3. `DungeonPortal` — таймер цикла, телепорт
4. `AuraComponent` — пассивные аурные эффекты этажей и персонажей
